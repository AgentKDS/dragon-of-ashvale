Dragon of Ashvale · multiplayer

Put your dragon game online

A step-by-step guide to putting the multiplayer version on GitHub and running it on Render, so anyone can play from a link in their browser. You don't need any coding tools, just a web browser.

Time: about 20 minutes Cost: free You need: an email address
0 of 12 steps done
    About the picturesThe pictures are simplified drawings of each screen, with the part to click circled in orange. GitHub and Render change their designs from time to time, so the real pages may look a little different. Look for the same button names.
    1

    Get the game files onto your computer

    GitHub needs the files from the game's server folder. Copy them somewhere safe first.

    1. In Claude, ask: "Open the server folder in File Explorer". A File Explorer window opens on that folder.
    2. Make a new folder for the game, for example Documents\dragon-of-ashvale. In File Explorer, open Documents, right-click an empty spot, choose New → Folder, and name it.
    3. Go back to the server folder, press Ctrl + A to select everything, then Ctrl + C to copy.
    4. Open your new folder and press Ctrl + V to paste.
    5. Check that the folder looks exactly like the picture: four files and one folder called public with index.html inside.
    dragon-of-ashvale/ ├── public/ │ └── index.html ← the game itself (about 260 KB) ├── .gitignore ← may be hidden; that's fine ├── package.json ← tells the server what to install ├── README.md ← notes about the server └── server.js ← the game server
    2

    Make a free GitHub account

    GitHub stores your game's code online, where Render can pick it up. Skip this step if you already have an account.

    1. Go to https://github.com and click Sign up in the top-right corner.
    2. Type your email address, a password, and a username. Your username shows in your game's GitHub address, so pick something you're happy to share (no real name needed).
    3. Solve the quick puzzle that checks you're a person, then click Create account.
    4. GitHub emails you a code. Open your email, copy the code, and type it into GitHub.
    5. It may ask a few questions about how you'll use GitHub. You can skip them.
    3

    Create a repository for the game

    A repository (or "repo") is a folder on GitHub that holds a project's files.

    1. Click the + button in the top-right corner of any GitHub page, then click New repository.
    2. In Repository name, type dragon-of-ashvale.
    3. Choose Public. Render's free plan works most simply with public repos. Anyone can see the code, but only you can change it.
    4. Leave Add a README file unticked, because the game already has one. Leave .gitignore and license set to None.
    5. Click the green Create repository button at the bottom.
    4

    Upload the game files

    You'll drag your folder's contents straight into the browser. No Git program needed.

    1. On the new, empty repository page, find the line "…or create a new file or upload an existing file" and click uploading an existing file.
    2. Open your dragon-of-ashvale folder in File Explorer and put the two windows side by side.
    3. In File Explorer, click inside the folder and press Ctrl + A to select everything, including the public folder.
    4. Drag the selection onto the dotted box in the browser and let go. A list of files appears under the box.
    5. Check that the list includes public/index.html. If it doesn't, finish this step anyway and then do step 5.
    6. Scroll down. Under Commit changes, the message can stay as "Add files via upload". Click the green Commit changes button.
    7. Wait a few seconds while it uploads. You'll land back on the repository page with your files listed.
    5

    Check the files, and fix a missing public folder

    Some browsers quietly skip folders when you drag them. The game page lives in public, so it must be there.

    1. Look at your repository's main page. You should see public (a folder), .gitignore, README.md, package.json and server.js. A missing .gitignore is fine.
    2. Click public. Inside should be index.html. If it's there, this step is done.
    3. If public is missing: on the repo's main page click Add file → Create new file. Don't use Upload files for this one, because it would put index.html in the wrong place.
    4. In the name box type public/. Typing the slash turns public into a folder. Then type index.html.
    5. Open index.html from your computer in Notepad (right-click → Open with → Notepad), press Ctrl + A, then Ctrl + C.
    6. Click in GitHub's big editing box and press Ctrl + V. It's a long file, so give it a moment.
    7. Click Commit changes…, then Commit changes again in the box that pops up.
    6

    Make a Render account using GitHub

    Render runs server.js on a computer that's always online and gives you a web address. Signing up with GitHub connects the two.

    1. Go to https://render.com and click Get Started (or Sign Up).
    2. Click GitHub to sign up with your GitHub account.
    3. GitHub asks whether to let Render use your account. Click Authorize.
    4. Render may ask you to confirm your email and answer a few questions. If it asks for a payment card, that's Render's rule at the time. The Free instance type you'll pick in step 8 doesn't charge.
    7

    Create a new web service

    A "web service" is Render's name for a program that runs all the time and answers visitors, which is what a game server is.

    1. On your Render dashboard, click + New in the top-right corner (it may say Add new).
    2. Choose Web Service. Not Static Site, because static sites can't run the server.
    3. Under Source Code, pick Git Provider and then GitHub if it asks.
    4. Find dragon-of-ashvale in the list and click Connect next to it.
    5. Repo not in the list? Click Configure account (or Configure GitHub). On GitHub, choose Only select repositories, pick dragon-of-ashvale, click Save, and go back to Render.
    8

    Fill in the settings

    These tell Render how to install and start the server. Copy them exactly. Use the Copy buttons to avoid typos.

    1. The Name becomes your game's address, so dragon-of-ashvale gives dragon-of-ashvale.onrender.com. If the name is taken, Render adds a few letters to the end, which is fine.
    2. Render often fills in Build Command with something like yarn. Delete it and paste npm install.
    3. Under Instance Type, scroll and pick Free.
    4. Don't add any environment variables. Render sets PORT by itself, and the server reads it.
    5. Click Deploy Web Service at the bottom (it may say Create Web Service).
    9

    Wait for it to go live

    Render downloads your code, installs the one library it needs, and starts the server. It takes 2–5 minutes the first time.

    1. Watch the Logs panel. Lines scroll past as Render works. That's normal.
    2. You're looking for two lines near the end: Dragon of Ashvale server on http://localhost:10000 (the number may differ) and Your service is live 🎉.
    3. The status badge at the top turns green and says Live.
    4. Your game's address is shown near the top, under the service name, like https://dragon-of-ashvale.onrender.com. Click it to copy or open it.
    5. If you see Build failed or Exited with status 1, see the troubleshooting table at the bottom.
    10

    Play, and test with two tabs

    Make sure multiplayer works before you send the link to friends.

    1. Open your onrender.com address. Under the Take flight button you should see a small green Online label.
    2. Type a nickname and click Take flight.
    3. Open the same address in a second tab (or on your phone), with a different nickname. Fly both dragons near each other. Each tab should see the other dragon and its name tag.
    4. Check the shared bots: both tabs should show the same bot names on the leaderboard (top right).
    5. When everything works, send the link to friends. Up to 30 players share a room. After that, a second room opens by itself.
    Free plan noteThe free server goes to sleep after 15 minutes with nobody playing. The next visitor waits about a minute while it wakes up. Then it's normal again. Render's paid instance types stay awake all the time.
    11

    Update the game later

    When the game gets new features, put the new version on GitHub and Render updates by itself.

    1. On GitHub, open your repository, click public, then index.html.
    2. Click the pencil icon (Edit this file) at the top-right of the file.
    3. Click inside the editor, press Ctrl + A, and press Delete.
    4. Open the new index.html in Notepad, copy all of it, and paste it into GitHub.
    5. Click Commit changes… → Commit changes.
    6. Render notices within a minute and redeploys (watch for Live again). Players already in the game should refresh the page.
